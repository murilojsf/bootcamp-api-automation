#This is a Vitest and SuperTest automation

This project uses Vitest and SuperTEst to perform automated API tests for a login feature and a user update feature.
 Vitest and SuperTest are JavaScript-based end-to-end testing framework that allows developers to write execute tests.


## Running
``` bash
# Run the login automation by command line
vitest run tests/login.test.js

# Run the produtos(Products) automation by command line
vitest run tests/produtos.test.js

# Run the produtos(Products) automation by command line
vitest run tests/usuarios.test.js

```
